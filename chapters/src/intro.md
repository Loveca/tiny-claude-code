# tiny-claude-code

这个项目会带你从零实现一个最小 coding agent。学习路径不是先读一大套框架源码，而是逐章实现一个真实可运行的 CLI agent：先能对话，再能调用工具、读写文件、控制权限、管理上下文，最后扩展成能处理真实项目任务的开发助手。

每章都会给出目标、核心概念、需要修改的文件、实现提示、测试命令和验收任务。单元测试使用 mock LLM，不需要 API key；验收任务使用真实 LLM，用来确认 agent 在真实交互中也能工作。

当前仓库代码已经实现到 Checkpoint 1。也就是说，`src/tiny_claude_code/` 不是纯 ch01 起点，而是包含 ch01-ch04 的完成态。阅读教材时，把每章当作“这一章引入了什么机制”的解释；如果要做真正的逐章练习，可以对照 `src/tiny_claude_code_ref/` 或回退到对应 git 提交。
