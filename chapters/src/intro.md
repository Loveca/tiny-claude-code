# tiny-claude-code

这个项目会带你从零实现一个最小 coding agent。学习路线不是先读一大套框架源码，而是逐章实现一个真实可运行的 CLI agent：先能对话，再能调用工具、读写文件、控制权限、管理上下文，最后扩展成能处理真实项目任务的开发助手。

每章都会给出目标、核心概念、需要修改的文件、实现提示、测试命令和验收任务。单元测试使用 mock LLM，不需要 API key；验收任务使用真实 LLM，用来确认 agent 在真实交互中也能工作。

当前仓库代码已经实现完整 ch01-ch15。阅读教材时，可以把每章当作“这个机制为什么会存在、它在 agent 运行时里解决什么问题”的解释；如果要做真正的逐章练习，可以对照 `src/tiny_claude_code_ref/` 或回退到对应 git 提交。

## 课程主线

这套教材不只是把功能堆出来。一个 coding agent 的核心其实很稳定：LLM 负责产生下一步意图，harness 负责保存状态、暴露工具、执行动作、处理错误并把结果喂回模型。后续章节引入的权限、Hook、上下文压缩、Todo、Subagent、后台任务和 Skills/Plugins，都是围绕这个核心循环扩展出来的运行时能力。

Part 1 建立最小闭环：ch01 讲 agent loop，ch02-ch04 讲工具协议、文件工具和工具注册表。你会看到“给模型看的 schema”和“本地真正执行的 handler”是两件事，注册表的价值是让循环不必知道每个工具的细节。

Part 2 加上运行时边界：ch05-ch07 讲权限、Hook 和错误恢复。这里的重点不是多写几个 if，而是把安全策略、生命周期扩展点、重试和降级这些横切逻辑从主循环里分离出来，让 agent 可以在真实项目里运行得更可控。

Part 3 处理长对话：ch08-ch10 讲上下文预算、压缩、会话和记忆。上下文窗口不是无限记忆，而是昂贵且有限的工作区；持久化 transcript、摘要和 memory 共同决定 agent 能不能跨多轮任务保持方向。

Part 4 进入复杂任务：ch11-ch13 讲 Todo、Subagent 和后台任务。Todo 把计划外部化，Subagent 通过上下文隔离拆分任务，后台任务把慢命令从主思考链路里移走。这些能力让 agent 不只是“一问一答”，而是可以组织工作。

Part 5 收束到可扩展产品形态：ch14 用真实项目挑战检验反馈闭环，ch15 讲 Skills 和 Plugins。Skills 更像可加载的知识包，Plugins 更像能力边界清晰的外部系统；二者让 agent 从一个固定程序变成可以按场景扩展的平台。

读完后，你应该能回答三个问题：模型到底只负责什么，本地 harness 必须兜住什么，以及每个扩展点为什么不能简单塞进 prompt 里解决。
